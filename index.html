Hola, amiguísima

Este espacio es para ti, incluso si todavía no te animas a cruzar la puerta del gimnasio.

El gym puede intimidar al principio. No tienes que descubrirlo todo sola.

Tal vez no conoces las máquinas, no sabes qué llevar o te preocupa verte perdida. Es normal. Primer Set nació para acompañarte con información fácil, situaciones reales y esa confianza que se construye poquito a poquito.
