PRIMER SET — NUEVO SITIO WEB
Archivos:
- index.html: página principal.
- landing.html: página con información ampliada.
- styles.css: identidad visual y estilos compartidos.

PUBLICAR EN GITHUB PAGES
1. Abre el repositorio Primer-Set.
2. Sube los tres archivos directamente a la raíz del repositorio (no dentro de otra carpeta).
3. Pulsa Commit changes.
4. En Settings > Pages, selecciona Deploy from a branch, branch main y carpeta /(root).
5. Espera a que GitHub Pages termine la publicación.
6. La página principal abre en la dirección del repositorio. La landing se abre agregando /landing.html al final.
